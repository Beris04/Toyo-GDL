TOYO FOODS · APP VISITAS MÓVIL V3.2 ESTABLE

OBJETIVO
Dejar la app usable para operación inmediata aunque Cloud tenga una falla temporal.

MEJORAS
- Diagnóstico Supabase dentro de Admin.
- Botones:
  Probar lectura / Probar escritura / Diagnóstico completo.
- Muestra el error real y una interpretación:
  API key, RLS, tabla, columnas, validación/check, red/CORS.
- Visitas y prospectos siguen guardándose localmente si Cloud falla.
- Promociones también:
  se guardan localmente y quedan en cola de sincronización.
- Botón Sincronizar reintenta visitas + promociones.
- Reintento automático al recuperar Internet.
- Indicador:
  Todo sincronizado / N pendientes.
- Se conserva interfaz, dashboard, mapa, prospectos, historial, promociones y enlaces externos.

PRUEBA URGENTE
1. Sube esta V3.2 a Toyo-GDL.
2. Entra como Admin.
3. Admin > Estado de Cloud > Diagnóstico completo.
4. Si dice:
   - Lectura OK + Escritura OK: Supabase está listo.
   - Lectura OK / Escritura falló: normalmente RLS/permisos o validaciones.
   - Lectura falló: revisar URL, anon key, RLS o tabla visits.
5. Haz una visita de prueba.
6. Si queda “pendiente”, pulsa Sincronizar.
7. Publica una promoción y prueba desde otro celular.
